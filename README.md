# Художник-склеротик

HTML5-игра (Vite + TypeScript, без фреймворков), рассчитана на телефон в вертикальной ориентации, работает и на компьютере.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/, озвучка копируется туда же
```

## Устройство

| Файл | Что внутри |
| --- | --- |
| `src/main.ts` | Запуск: стартовый экран → видео (пока грузится музыка и шрифты) → «Включите звук» → главный экран |
| `src/menu.ts` | Главный экран: баллы, следующий раунд (сначала — нулевой), кнопки «Обучение» и «Видео-урок», пройденные раунды с переигровкой |
| `src/lesson.ts` | Раунд 0 — интерактивное обучение: 5 слов, правила и все способы ходить по ячейкам, шаг за шагом |
| `src/tutorial.ts` | Обучающий ролик `video/tutorial.mp4` по кнопке «Видео-урок» (сам не включается) |
| `src/round.ts` | Раунд: экраны подготовки → диктовка → 30 секунд → опрос по 9 ячейкам → итоги |
| `src/hud.ts` | Панели поверх поля, общие для раунда и обучения: шапка, инструменты, опрос |
| `src/board.ts` | Поле 5×5 на canvas: камера, маркер, переходы между ячейками |
| `src/audio.ts` | Музыка, голос (Web Audio) и простые звуковые эффекты |
| `src/content.ts` | Раунды из `voiceover/manifest.json`, задержка раунда, подписи «Диктует …» |
| `src/answer.ts` | Сравнение ответа: без регистра, «е/ё», пунктуации и пробелов |
| `src/progress.ts` | Прогресс в `localStorage` |
| `src/vk.ts` | VK Bridge: `VKWebAppInit` при запуске, если игра открыта во ВКонтакте |
| `src/ads.ts` | Межстраничная реклама VK (`interstitial`) перед переигровкой пройденного раунда |
| `voiceover/tutorial/` | Обучение: тексты подсказок и слова (`script.json`) и их озвучка в MP3 (`generate_tutorial.py`) |
| `video/tutorial/` | Обучающий ролик: сценарий (`SCRIPT.md`), запись экрана игры (`record_ui.mjs`), сцены из Gemini Omni и сборка `make_tutorial.py` |

Номер ячейки в опросе вырезается из `dictation.mp3` по таймингам манифеста, поэтому в сборку попадают только `dictation.mp3` и `lines/*.wav` каждого раунда, а от обучения — его MP3.

## Задержка

Голос называет номер, через секунду — слово, потом молчит: это **задержка**, после неё звучит следующий номер.

| Раунды | Задержка | Оформление |
| --- | --- | --- |
| 1–6 | 3 секунды | мятная «утренняя» гамма, `.delay-3` |
| 7–10 | 2 секунды | основная тёплая гамма, `.delay-2` |
| 11–16 | 1 секунда | синяя «ночная» гамма, `.delay-1`, «Сложный раунд» |

Задержки задаёт `DELAYS` в `voiceover/generate_voiceover.py`; поменять их можно без новых запросов к API — дорожки соберутся из кэша:
`python -X utf8 generate_voiceover.py generate --rounds 1-6 --force`. Игра берёт задержку из `word_pause_ms` манифеста,
цвета — из `.delay-N` в `styles.css` и `PALETTES` в `board.ts`.

## Обучение (раунд 0)

Новый игрок начинает с раунда 0. Пропустить его можно ссылкой «Я уже умею играть», пройти заново — кнопкой «Обучение».
Ведущий (голос Laomedeia, как в ролике) объясняет правила, голос раунда (Achird) диктует пять слов. Каждый шаг ждёт игрока:
коснуться ячейки на поле, стрелка к следующей, «Отменить», касание соседней ячейки, «Отдалить», кнопка с динамиком,
на компьютере — клавиатура, затем «Готово», опрос по трём ячейкам и рассказ о задержке. Баллы обучения в счёт не идут.

```bash
cd voiceover
set GEMINI_API_KEY=...
python -X utf8 generate_tutorial.py generate   # tutorial/lines, numbers, words (*.mp3) и manifest.json
python -X utf8 generate_tutorial.py verify     # распознаёт каждый клип и сверяет с текстом
```

Тексты меняются в `voiceover/tutorial/script.json`, после правки — `generate --retake <id>`. Без MP3 обучение работает по тексту.

Если Google API недоступен напрямую, оба генератора озвучки ходят через прокси с тем же API:
`set GEMINI_API_BASE=https://<прокси>` (без `/v1beta`). Ключ по-прежнему уходит заголовком `x-goog-api-key`.

## ВКонтакте

Игра — VK Mini App. VK Bridge включается, только когда игра открыта во ВКонтакте (iframe или WebView с `vk_app_id` в адресе). Тогда при запуске уходит `VKWebAppInit` и `VKWebAppCheckNativeAds` для предзагрузки рекламы, а перед переигровкой раунда — `VKWebAppShowNativeAds` с `ad_format: 'interstitial'`. Если VK рекламу не показал, раунд всё равно начинается. В обычном браузере (`npm run dev`) реклама пропускается.

## Отладка

В режиме `npm run dev` в консоли браузера доступны `__round.skip()` (завершить диктовку или 30 секунд), `__lesson` (текущее обучение) и `__audio`. Сбросить прогресс: `localStorage.clear()`.
